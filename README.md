# Bobo na Mi

A puzzle game in Sierra Leonean Krio, inspired by *Baba Is You*. Push word tiles to make sentences
like **BOBO NA MI** ("boy is you") and change the rules of each level, then reach the flag.

**Play it in your browser:** https://togetherings.github.io/bobo-na-mi/

Made with [EduGame Kit](https://github.com/togetherings/edugame-kit) as a **Saved Game**: each
learner's progress is kept, with no scores. One zip works in Kolibri (through Kolibri Studio),
Moodle and other SCORM 1.2 learning systems, and RACHEL; the kit also makes a Sugarizer activity and
a Kiwix file. Plain HTML5 and JavaScript: no libraries, no build step for the code.

## Get the game

- **For schools:** download the zip from the latest
  [release](https://github.com/togetherings/bobo-na-mi/releases). In Kolibri Studio, add it to a
  channel as an HTML5 app. In Moodle, add it as a SCORM package. For RACHEL, unzip it into the
  modules folder.
- **To try a change:** every push builds the zips; open the **Actions** tab, the latest **Build**
  run, and download **game-zips**.

## What's saved

The kit's helper saves where the game runs (the learner's Kolibri or Moodle account, Kolibri
Games, Sugarizer's Journal, or the browser). The save holds only what the learner has done, in a few
hundred characters (the limit everywhere but Kolibri Games is 3,900):

- the fewest moves for each main level they've solved (shown with a ✓);
- the keys they changed;
- the levels they made in the editor, as **level codes**.

It saves straight away after each change, because Kolibri drops a save made as the learner leaves.
When every main level is solved, the game tells the platform the activity is done, which Kolibri
shows.

## Playing

| Action | Keys (change them in Keys) | Touch |
|---|---|---|
| Move | Arrow keys / W A S D | Arrow pad |
| Wait (skip a turn) | Space / . | ● in the arrow pad |
| Undo (rewind, unlimited) | Z / Backspace | ↶ |
| Restart (can be undone) | R | Restart |
| Back | Esc / P | ◀ |

**Options** (the kit's panel): appearance, language (English, French), on-screen buttons, sound,
and showing what the rules mean under the grid.

**Level editor:** paint things and words, test, save in Your levels, and share a level as a code
(Export and Import). Coaches can hide the editor on the Kolibri Games games page (the `editor`
setting).

## Making changes

```bash
pip install git+https://github.com/togetherings/edugame-kit.git
edugame preview .                   # play it in the kit's test page
node tests/test_levels.js           # level tests
python3 tests/browser_test.py       # browser test (needs Playwright)
edugame build . -o dist             # the zips
```

- **New main level:** add it to `BNM.LEVELS` in `src/levels.js` with a new `id` (never change an
  existing id: saves use it), its meaning in every `lang/*.json` (`level.<id>`), and its solution
  in `tests/test_levels.js`. A level made in the editor can be added as `{ id: '...', code: 'BNM1|...' }`.
- **New word:** see the top of `src/words.js`.
- **New language:** `edugame translate . sw`, then translate `lang/sw.json`.
- **Releasing:** change `version` in `edugame.json` and `BNM.VERSION` in `src/main.js` (a test
  checks they match), add a section to `CHANGELOG.md`, merge, then draft a release in **Releases**
  with a tag like `v0.2.0`. The Build workflow attaches the zips.

## Art

The pictures come from **Petixel** packs bought on itch.io: Base Characters, Hair, Prototype and
Main UI (the same packs Plenty Heaps uses). They may be edited, but **must not be used to train
image-generation AI**, and they can't be shared as packs.

- **The packs are not in this repository**, which is public. Keep them on your own computer in
  `art-src/` (any folder layout); `.gitignore` keeps that folder out of git.
- `assets/` holds only the pictures the game uses, built by `python3 tools/build_assets.py`. Run it
  after changing art or adding a word: it reads the words from `src/words.js`.
- **Bobo, Titi and Padi** are made by a palette swap of Petixel's child body and hair sheets (each
  has their own skin, hair and clothes), the way Plenty Heaps makes its characters.
- **Word tiles** are spelled with the letters of the Prototype tileset (W is an upside-down M).
- WATA and FAYA have no picture in these packs, so `src/sprites.js` draws them.
